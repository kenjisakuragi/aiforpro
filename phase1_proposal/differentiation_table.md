## 3. 弊社の差別化ポイント（提案書本文に転記）

1. **成果報酬型で初期投資ゼロから始められる**
   - 削減コストが出てから報酬を受領。事務所側のリスクが極小。
2. **士業の業務に特化したテンプレート資産**
   - 顧問先連絡・契約書レビュー・判例調査・税務相談ドラフト等、業界別の実装ストックを保有。
3. **LLM × ワークフロー自動化（n8n / Make）の組合せ設計**
   - 単発の生成AIツール導入ではなく、業務フロー全体での効率化を設計。
4. **守秘義務・データ取扱いを契約段階で明文化**
   - 弁護士法23条・税理士法38条を踏まえた取扱合意書をテンプレート化。
5. **エンジニア法人による継続支援**
   - PoC後の運用保守・改善を月額で継続。属人化を避け、事務所内で再現可能な状態を残す。

## 4. 提案先タイプ別の刺さるメッセージ

| 提案先タイプ | 刺さる訴求 |
|---|---|
| 「ITに弱い」と感じている所長 | 初期費用ゼロ／非エンジニアでも触れるUI／日本語のエラーメッセージ |
| 既にAIを試したが効果が出ていない事務所 | 単発ツールではなく業務フロー設計／成果指標の事前合意 |
| 顧問料の値下げ圧力に苦しむ事務所 | 顧問1社あたり工数削減 → 顧問先キャパ拡大による売上増 |
| 採用難・属人化に悩む事務所 | 中堅人材の業務をAIが補助 → 新人でも定型業務を捌けるように |
