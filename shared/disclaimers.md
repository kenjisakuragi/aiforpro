# AI生成物の注記文言（標準テンプレート）

すべての成果物（提案書・分析レポート・自動生成された書類ドラフト等）には、以下の注記を必ず付すこと。
利用シーンに応じて短文版・長文版を使い分ける。

-----

## 1. 短文版（書類フッタ・メール末尾用）

> ※本書類はAIにより生成されたドラフトです。最終的な確認・判断は、{{有資格者の肩書き：税理士／弁護士など}} が行います。

英語版：
> This document is an AI-generated draft and must be reviewed and approved by a qualified {{tax accountant / attorney}} before use.

-----

## 2. 中文版（提案書・レポートの冒頭ページ用）

> 【AI生成物に関する注記】
> 本書面は、生成AIを用いて作成されたドラフトです。
> 記載内容には事実誤認・推論誤りが含まれる可能性があります。
> 税務判断・法律判断は、必ず {{担当税理士／担当弁護士}} の確認を経たうえでご活用ください。
> 個別の事案については、別途ご相談ください。

-----

## 3. 長文版（契約書添付・ガバナンス文書用）

```
【AI生成物の取扱いに関する確認事項】

1. 本サービスにおいて生成される文書・分析・スクリプト等（以下「AI生成物」という）は、
   コンサルタントが提供する生成AI技術を用いて作成された参考資料であり、
   税務判断・法律判断その他の専門判断を構成するものではありません。

2. AI生成物の最終的な内容確認、修正、採否の判断は、依頼事務所に所属する
   {{税理士／弁護士／その他有資格者}} が行うものとします。

3. AI生成物には、以下の限界が存在することを依頼事務所は了承します。
   - 学習データの時点的限界による情報の古さ
   - 個別事案への適用妥当性の不確実性
   - 事実関係の誤認（ハルシネーション）の可能性

4. AI生成物に起因する第三者（顧問先・依頼者を含む）への損害については、
   コンサルタントは、別途締結するサービス契約書に定める範囲でのみ責任を負います。

5. AI生成物の生成にあたり、依頼事務所が提供するデータ（顧問先情報・依頼者情報を含む）の
   取扱いについては、別途締結する秘密保持契約および個人情報取扱合意書に従います。
```

## 4. 業界別の追加文言

### 税理士事務所向け

> 本書面は税理士法第2条第1項に定める税理士業務の代行を目的とするものではありません。
> 税務代理・税務書類の作成・税務相談はすべて、貴所所属の税理士の責任において行われます。

### 弁護士事務所向け

> 本書面は弁護士法第72条に抵触する法律事務の取扱いを目的とするものではありません。
> 法律判断・代理行為はすべて、貴所所属の弁護士の責任において行われます。
> なお、依頼者情報を含むデータの取扱いについては、弁護士法第23条および
> 弁護士職務基本規程第23条に基づく守秘義務に配慮した運用を行います。
