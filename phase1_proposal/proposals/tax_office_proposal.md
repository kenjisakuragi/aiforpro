## Slide 3：税理士業界の構造的課題（業界共通認識の確認）

```
1. 顧問料の長期下落圧力
   - クラウド会計の普及で「記帳代行」の付加価値が薄れる
   - 顧問1社あたりの単価上昇は難しく、件数で稼ぐ構造に

2. 慢性的な人材不足
   - 税理士試験合格者数：減少傾向
   - 補助スタッフ採用も都市部で逼迫

3. 繁忙期の極端な偏在
   - 1〜3月（個人確定申告）／3〜5月（法人決算）
   - 残業規制とのトレードオフが厳しくなっている
```

**訴求のポイント**
> どれも「人を増やす」では解決しない構造課題です。
> 1人あたりの処理キャパを上げることが、唯一の打ち手になりつつあります。

## Slide 12：守秘義務・データ取扱い

```
1. NDAを契約と同時に締結します。
2. 顧問先の実データはコンサルの開発環境に持ち込みません。
   ─ 開発・デモはすべて仮データ。実装後の運用は御所ネットワーク内で完結。
3. 使用するLLM（Claude API等）は学習に入力データを使用しないプランで運用します。
4. AIが生成した書類には必ず「税理士による要確認」の注記を付与します。
   ─ 税理士法第2条に抵触しない設計を徹底します。
```

## Slide 13：弊社が選ばれる理由

```
1. 成果報酬型 ── 初期投資ゼロから始められる
2. 士業特化 ── 業界別のテンプレ資産（顧問先連絡／税務相談／決算レポート 等）
3. 元エンジニアの法人 ── 株式会社契約／継続支援／属人化させない設計
4. 業務フロー全体を設計 ── 単発のAIツール導入ではなく、現場で回る仕組みに
5. 法務配慮 ── 守秘義務・有資格者承認フローを契約段階で明文化
```

> 詳しくは別添「競合差別化比較表」をご参照ください。
