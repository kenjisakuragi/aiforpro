# Outreach：知人経由・初回打診用スライド

ヒアリング前の段階で、知人経由で打診する2事務所向けに作成した10スライド構成の打診版。
受諾後（ヒアリング日程確定後）に、`demo/` のテンプレを使って本格提案版（15スライド・実数値入り）を作成する。

## ファイル

| ファイル | 提案先 | サイト |
|---|---|---|
| `daikanyama_intro.md` | 代官山綜合法律事務所 様 | https://daikanyamalaw.com/ |
| `hillford_intro.md` | ヒルフォード法律事務所 様 | https://hillford-law.com/ |

## 提案スタンス（共通）

```
今回：打診版（10スライド・無料診断のCTA）
  ↓ ヒアリング受諾
次回：本格提案版（15スライド・実数値ROI／PoC候補確定）
  ↓ PoC受諾
    Phase2 業務分析 → Phase3 実装 → Phase4 効果測定
```

- 打診版は **「商談ではなくご挨拶」** の建付け。決断を求めない。
- ROI 数値は出さない（業界平均レンジのみ提示）。**実数値はヒアリング後**。
- CTA は **無料の業務棚卸し診断（60〜90分）** の日程候補3つを依頼。

## 提案前チェックリスト（必読）

### 利益相反（最重要）
- [ ] **TBSテレビ（本業）との利益相反確認**
  - 代官山綜合：エンターテイメント法務／スポーツ法務に注意。TBSの取引先・出演契約・スポーツ放映権関連と重なる可能性
  - ヒルフォード：取扱分野によっては放送・メディア関連の案件があり得るため要確認
- [ ] 株式会社 VIBE SHIP（あなたの法人）の他クライアントとの利益相反

### 内容
- [ ] 表紙の事務所名・敬称に誤字がないか
- [ ] 「公開情報ベース」の所感が、御所の実態と齟齬がないか（齟齬がありそうな項目はプレースホルダ化）
- [ ] 紹介者（`{{ INTRODUCER_NAME }}`）の氏名表記について、紹介者本人の了承を得たか
- [ ] 「AIドラフト・要確認」の注記が冒頭または末尾に入っているか
- [ ] 連絡先（メール・電話・HP）が実値に差替えられているか

### 守秘義務
- [ ] 打診段階での守秘範囲（本資料の取扱い）について、メール送付時に文言を添えるか確認
- [ ] PDFのプロパティ（作成者・タイトル）に不要な個人情報が残っていないか確認

### 紹介者への配慮
- [ ] 紹介者経由の打診であることを Slide 2「本日の趣旨」に明記
- [ ] 紹介者へCC／BCCの方針を事前に擦り合わせ

## 受諾後の流れ（参考）

1. ヒアリング日程確定 → `hearing_sheets/law_office_hearing.md` を準備
2. ヒアリング実施（60〜90分） → 議事録・所要時間データ取得
3. ROI試算 → `roi/roi_input_template.csv` に入力 → `roi_calculator.py` 実行
4. **本格提案版を作成** → `demo/law_office_slides.md` を雛形に、御所固有の数値を埋め込む
5. 第2回MTGで本格提案版を提示 → PoC合意
