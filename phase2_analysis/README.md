# Phase 2：業務分析フェーズ

ヒアリング後、自動化対象業務の優先順位付けと実装方針を固めるためのアウトプット置き場。

## ファイル

- `automation_scoring_template.csv` … 業務単位の自動化適性スコアリング表

## スコアリング項目の意味

| 列 | 評価軸 | 1（低） … 5（高） |
|---|---|---|
| 定型度 | 入出力フォーマットの固定度 | 都度判断 … 完全定型 |
| データ標準化 | 入力データの構造化度合い | 紙・自由記述 … 構造化API |
| 判断介在度 | 専門判断の必要度 | 機械処理可 … 高度判断必須 |
| 法的リスク | 誤りが法的責任に直結する度合い | 軽微 … 重大（要有資格者承認） |
| 実装難易度 | 構築工数・連携複雑度 | 数日 … 数ヶ月 |

## 優先順位の考え方

横軸：削減効果（月間所要時間 × 削減見込み率 × 担当者時給）
縦軸：実装難易度（低いほど良い）

第1象限（削減効果大 × 難易度低）から順にPoC候補を抽出する。

## 次フェーズへの橋渡し

このCSVで上位3〜5件を選定したら、Phase 3（実装）の対応ディレクトリ（`tax_office/` または `law_office/`）にスクリプトを起こしていく。
