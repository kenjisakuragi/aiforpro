# Phase 4：成果測定・報告フェーズ

PoC・本格導入後の効果測定とクライアント報告用の成果物。

## ファイル

- `kpi_dashboard_template.html` … 月次KPIダッシュボードのHTMLテンプレ。`{{ ... }}` のプレースホルダをレポート生成スクリプトで差替えて使用。

## 計測対象（標準セット）

- 月間削減時間（h/月）
- 月間削減コスト（円）
- 削減率（業務単位）
- 成果報酬額（当月）
- 品質指標（差戻し率・要修正率など、業務に応じて追加）

## 運用フロー

1. 各業務の自動化スクリプトに、実行ログ（処理件数・処理時間）を残す
2. 月初にログ集計＋事務所ヒアリング（実所要時間の自己申告）で数値確定
3. `kpi_dashboard_template.html` を埋めてクライアントに送付
4. 同月の請求書・成果報酬計算書も同時送付
